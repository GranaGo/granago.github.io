# GranáGo

**GranáGo** es una plataforma integral de movilidad diseñada específicamente para la ciudad de Granada. Este es un **proyecto personal** sin ánimo de lucro desarrollado con el objetivo de unificar en una sola herramienta datos de transporte, tráfico y servicios municipales en tiempo real.

## 📊 Fuentes de Información

La precisión de GranáGo es posible gracias al uso de datos abiertos y APIs de diversas instituciones oficiales y plataformas colaborativas:

* **Transporte Público:** Datos GTFS y tiempos de llegada proporcionados por el **Consorcio de Transporte Metropolitano de Granada**.
* **Tráfico y Seguridad Vial:** Ubicación de radares, cámaras de vigilancia e incidencias suministradas por la **DGT (Dirección General de Tráfico)** y el **Ayuntamiento de Granada**.
* **Aparcamientos:** Estado de ocupación en tiempo real del portal de movilidad del **Ayuntamiento de Granada**.
* **Combustible:** Precios de carburantes actualizados diariamente a través del **Ministerio de Industria, Comercio y Turismo**.
* **Cartografía:** Mapas proporcionados por **OpenStreetMap** y estilos de **CartoDB**.
* **Clima y Calidad del Aire:** Previsiones meteorológicas y niveles de AQI obtenidos de **Open-Meteo**.

---
*Nota: GranáGo no es una aplicación oficial de ninguna de las entidades mencionadas anteriormente. Es una herramienta de visualización de datos de dominio público.*
